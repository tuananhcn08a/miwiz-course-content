# icons/

- Source: https://github.com/microsoft/fluentui-emoji (Fluent Emoji, 3D style)
- Licence: MIT (c) Microsoft Corporation. https://github.com/microsoft/fluentui-emoji/blob/main/LICENSE
- Fetched with `scripts/fetch-fluent-icons.py` (miwiz-mobile). File name = lowercase snake case of the emoji name.
- Do not edit by hand; re-run the script to add icons.
